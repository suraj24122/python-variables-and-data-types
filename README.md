# Basic Python Practice Programs 🐍

This repository contains beginner-friendly Python programs designed to help understand fundamental programming concepts such as variables, input/output, data types, arithmetic operations, and type conversion.

## 📂 File Descriptions

### `program_1.py`  
Stores and prints personal information (name, age, and city) using basic printing and string formatting.

### `program_2.py`  
Demonstrates swapping two numbers:  
- Using a third (temporary) variable  
- Without using a third variable (if added)

### `program_3.py`  
Takes two numbers as input and calculates their:  
- Sum  
- Difference  
- Product

### `program_4.py`  
Checks and prints the data types of different types of variables:  
- Integer  
- String  
- Float  
- Boolean

### `program_5.py`  
Covers type conversion examples:  
- Float to Integer  
- String to Integer  
- Also demonstrates what happens when trying to convert a non-numeric string to an integer

### `program_6.py`  
Takes user input (name and age) and displays a friendly greeting message.

### `program_7.py`  
Calculates the area of a rectangle using user inputs for length and breadth.

## 🛠️ Requirements

- Python 3.x  
No external libraries are required.
